# Scientific triage and progressive delivery

Use the [shared scientific review](../core/scientific-review.md). Inventory once, identify the main question/contribution and quote the most consequential claims before deep analysis.

Deliver an early bounded triage: contribution; highest-impact logical risk; highest-impact technical risk; core claim with missing evidence; next verification that can change the conclusion. Include locations and reviewed scope. If no issue has been established, say so; do not fill categories with invented defects. Mark a suspected problem as provisional and explain what would falsify it.

Next, deepen only relevant alternative, contract, evidence and prior-work checks. Share the current hash-bound argument graph across these passes. Resolve contradictory findings by revisiting their premises and artifacts, not by averaging reviewer opinions. Record explicit changes of judgment when new evidence arrives.

Finish with Priority Findings, Research Validation Tasks, Required Manuscript Changes, Suggested Language Edits, Venue Compliance and Verification Limitations. Keep hypothesis tests separate from prose corrections. Preserve modes and approvals; review and suggested edits leave originals unchanged. Chat-only requests need no generated files; saved reports use the [output policy](output-policy.md).
